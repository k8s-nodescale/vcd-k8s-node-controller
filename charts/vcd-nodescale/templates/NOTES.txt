  kubectl -n {{ include "vcd-nodescale.namespace" . }} create secret generic {{ .Values.vcd.existingSecret }} \
    --from-literal=url=https://vcd.example.com/api \
    --from-literal=user=svc-node-controller \
    --from-literal=password='***' \
    --from-literal=org=myorg \
    --from-literal=vdc=My-VDC-Name \
    --from-literal=insecure=false

The chart generated the two accounts. Read the passwords once, then delete the
key so they stop existing:

  kubectl -n {{ include "vcd-nodescale.namespace" . }} get secret {{ .Values.ui.auth.secretName }} \
    -o jsonpath='{.data.initial-passwords}' | base64 -d

  kubectl -n {{ include "vcd-nodescale.namespace" . }} patch secret {{ .Values.ui.auth.secretName }} \
    --type=json -p '[{"op":"remove","path":"/data/initial-passwords"}]'

Rotate a password with "htpasswd -nB <user>" and put the hash into the
users.yaml key of that Secret; the page picks it up within
{{ .Values.ui.auth.refreshInterval }} without a restart.
